One-time token setup

Publishing commits data/season.json straight to the repo using the GitHub API — that push triggers the Pages deploy, so the live site updates automatically in a minute or two.

  1. Create a fine-grained personal access token at github.com → Settings → Developer settings → Fine-grained tokens.
  2. Give it access to this repository only, with Contents: Read and write permission.
  3. Paste it below. Tick “remember” to keep it in this browser (stored only on your device).

Prefer not to use a token? Use Download season.json above and commit the file to data/season.json yourself.
